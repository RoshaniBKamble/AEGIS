# AEGIS

**Your AI. Under Your Control.**

AEGIS is a sovereign personal AI agent. It reasons inside **0G Private Computer** (verified, private inference) and can plan and execute tasks — but every sensitive, high-value or irreversible action is held at the **Human Gate** until a real person provides a fresh **World ID** proof.

---

## Product tour

| Surface | What it does |
| --- | --- |
| **Landing** (`/`) | Cinematic hero with a live neural particle field and the Human Gate preview. |
| **Console** (`/app`) | Chat/task interface. Every reply streams from the 0G adapter and carries a request ID + attestation badge. Planned actions appear as *Action intent* cards. |
| **Human Gate** | Full-screen verification moment with orb scanner, countdown ring and four outcomes: **Approve**, **Deny**, **Cancel** (or `Esc`), **Expire**. A *Simulate invalid proof* switch demonstrates the failure path. |
| **Autonomy Policy** (`/app/policy`) | Presets (Guardian / Balanced / Operator), auto-approve risk ceiling, per-category rules (Auto / Human Gate / Block), verification window and a live decision simulator. |
| **Audit Log** (`/app/audit`) | Timeline of inferences, auto-approvals, human verifications and stops, with 0G request IDs, attestations, nullifiers and execution references. Exportable as JSON. |
| **Identity** (`/app/identity`) | Profile, World ID link status, 0G node status, verification history and a local-vault wipe. |

### Decision engine

```
agent plans action ──► policy.evaluate(category, risk)
                        ├─ Block        → aborted, agent explains
                        ├─ Auto (≤ ceiling) → executed, logged as auto-approved
                        └─ Human Gate   → World ID modal
                                           ├─ verified → executed (proof logged)
                                           └─ denied / cancelled / expired / invalid → aborted
```
Hard floor: `critical` risk and `irreversible` actions can never auto-run.

## Architecture

```
frontend/  React 19 · Tailwind · Framer Motion · shadcn primitives
  src/context/AegisContext.jsx   agent state machine, gate resolution, audit logging
  src/lib/zerog.js               SSE client for the 0G inference adapter
  src/lib/worldid.js             World ID proof request + server verification (demo)
  src/lib/policy.js              presets, evaluation, policy hash
  src/lib/storage.js             IndexedDB (chats, audit) + localStorage (policy, profile)
  src/components/gate/*          Human Gate modal, orb scanner, action manifest
  src/components/console/*       message stream, badges, composer, session panel
  src/pages/*                    Landing, Console, Policy, Audit, Identity

backend/   FastAPI
  server.py   /api/agent/think (SSE) · /api/zerog/status · /api/worldid/verify
  zerog.py    0G Private Computer adapter (prompting, action parsing, proof envelope)
```

All user data stays in the browser. The backend is stateless.

## Demo mode

Demo mode lets anyone experience the complete flow without 0G or World ID credentials:

- **Reasoning is real** — a hosted model produces every plan and reply.
- **0G envelope is simulated** — request IDs, provider address and attestation hashes are generated by `backend/zerog.py`.
- **World ID is simulated** — `requestHumanProof()` returns a proof-shaped object that the backend accepts in demo mode.

Try: *"Send 0.5 ETH to mira.eth for the studio deposit"* → approve, then try again and deny, cancel, wait out the timer, or tick *Simulate invalid proof*.

## Going live

### 0G Private Computer
See the header of `backend/zerog.py`. Replace the gateway call in `ZeroGPrivateComputer.stream()` with a request to the provider endpoint returned by the 0G Serving Broker, signed via `broker.inference.getRequestHeaders`, and verify each response with `broker.inference.processResponse`. Return the real chat ID and TEE signature in the `meta` / `done` events — the UI already renders them.

### World ID (IDKit / Agent Pass)
See `frontend/src/lib/worldid.js` and `worldid_verify` in `backend/server.py`.
1. Create an app and an incognito action `aegis-human-gate` in the World Developer Portal.
2. `yarn add @worldcoin/idkit` and swap `requestHumanProof()` for the IDKit widget/hook inside `HumanGateModal`, using the action ID as the signal.
3. In `worldid_verify`, forward the proof to `https://developer.worldcoin.org/api/v2/verify/{app_id}` and persist used nullifiers per action.
